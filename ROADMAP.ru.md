# Дорожная карта ClamGuard

Стадия: 0.2.1

Этапы идут по порядку: `[x]` — сделано, `[ ]` — в планах. Текущий этап — первый незавершённый.

## Сканирование
- [x] Движок ClamAV (Cisco Talos) прямо в приложении, без root
- [x] Быстрая, полная и выборочная проверка с прогрессом
- [x] Проверка APK и общего хранилища
- [x] Обновление вирусных баз, в том числе по расписанию
- [x] Сканирование запускается только при установленных базах

## Реакция на угрозы
- [x] Карантин, удаление или игнорирование найденного
- [x] Экран карантина с восстановлением файлов
- [x] Защита в реальном времени: проверка устанавливаемых приложений

## Надёжность на Android
- [x] Сканирование и обновление баз в foreground-сервисе
- [x] Прогресс и результат переживают переключение приложений
- [x] Расширенный режим с root через модуль Magisk

## Распространение
- [x] Релизы на GitHub: APK для `arm64-v8a` и модуль Magisk отдельными файлами
- [x] Сборка в CI на каждый push
- [x] Собственный репозиторий F-Droid на keytron-prime.org
- [ ] APK с релизной подписью вместо отладочной
